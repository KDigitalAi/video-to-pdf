📋 Upload Format Requirements

You can upload either:

  • .vtt - One or more subtitle files (must start with WEBVTT). Do not mix with CSV in the same upload.
  • .csv - A single manifest (only one CSV per upload) with the following columns:
  • course - Course name
  • module - Module name
  • module_index - Module number (for ordering)
  • video_title - Video title
  • video_url - Full Vimeo URL (e.g., https://vimeo.com/123456789)
  • video_index - Video number within module
